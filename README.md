# ⏱️ Sistema de Registro de Ponto

Projeto de um sistema backend para controle e gerenciamento de marcações de ponto de funcionários, focado em boas práticas de manipulação de datas, ordenação e persistência de dados.

---

### 🎯 Objetivos do Projeto
- Estruturar e modelar um banco de dados relacional para registros de ponto.
- Garantir a ordenação e manipulação correta de datas e horários (`DATETIME`).
- Integrar o banco de dados MySQL com uma aplicação backend em Java.

---

### 🛠️ Tecnologias
- **Linguagem:** Java
- **Banco de Dados:** MySQL
- **Gerenciador de Dependências:** Maven
- **Ambiente:** GitHub Codespaces

---

### 🗄️ Estrutura Inicial do Banco
* **`funcionarios`**: Armazena o cadastro dos colaboradores (ID, nome e cargo).
* **`marcacoes`**: Registra as entradas e saídas vinculadas ao colaborador com timestamp de data/hora.
